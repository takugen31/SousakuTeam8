# MeterGame

## 起動・配置

- シーン: `Assets/MeterGame/Scenes/TensionManagementMinigame.unity`
- Unity 6000.3.6f1 で開き、Play すると自動で開始。
- Game ビューを選択して **Space キーを長押し**するとゲージが連続的に増える。既定はHoldモード。入力方式をPressに変えると1回押すごとの加算になる。
- このゲーム専用の Scripts / Art / Scenes / Tests はすべて `Assets/MeterGame/` 配下に配置する。

## ゲーム仕様

1. 操作ゲージは初期値 **80%**、右側のハートは **0%** から始まる。
2. 操作ゲージは常に減少し、Space の押下で増える。0〜100% に制限する。
3. 薄い色の枠が目標範囲。範囲の位置・幅・変化にかける時間をランダムに選び、滑らかに移動・伸縮する。ときどき速い移動や狭まりが起きる。白い縦線が現在の操作ゲージ量。
4. 操作ゲージの先端を範囲内に **連続して指定秒数**とどめると、その後の範囲内滞在時間に応じて右のハートが下からたまる。待機秒数を超えた分だけ加算する。
5. 既定では範囲外に出ると連続滞在時間をリセットし、獲得済みのハート量は保持する。調整項目で範囲外の猶予時間やハートの減少を設定できる。
6. ハートが **100%** になった時点で成功。ゲーム全体の制限時間が過ぎても100%未満なら失敗。制限時間ちょうどに100%になった場合は成功。
7. 成否確定後は操作・ゲージ・範囲・ハートを停止。成功時はハートを明るいピンク、失敗時は操作ゲージをくすんだ色にする。

ゲージが0%・100%になっただけでは成否は確定しない。成功を決めるのは右のハートの蓄積量。

## Inspector での調整

Hierarchy の **MeterGameCanvas → Meter Game Controller** に日本語の専用Inspectorを表示する。
量・幅・位置・確率は **0〜1（1 = 100%）**、時間は秒、速度倍率は **1が標準・2が2倍・0が停止**。
Play中も調整でき、Inspector下部で現在値を確認できる。「現在の設定で再スタート」で最初から試せる。

### 操作バー・入力

**入力方式の切り替え手順**

1. Hierarchyで `MeterGameCanvas` を選ぶ。
2. Inspector の **Meter Game Controller → 操作バー・入力 → 入力方式** を変更する。
3. **押すたびに増加**（Press）または **長押しで連続増加**（Hold）を選ぶ。Play中にも切り替え可能で、ゲージや残り時間はリセットしない。

「押すたびに増加」は押した瞬間に「1回押した時の加算量」を加算する。「長押しで連続増加」はSpaceを押している時間に応じて「長押し中の加算量 / 秒」を滑らかに加算し、押した瞬間の追加加算は行わない。使わない方式の加算量はInspectorでグレー表示になる。

長押し中の実際の変化量は **（長押し中の加算量 / 秒 − 自然減少量 / 秒）× バー速度倍率**。既定値では `(0.5 − 0.25) × 1 = 0.25` なので毎秒25ポイント増加する。Spaceを離すと毎秒25ポイント減少する。加算量を自然減少量より小さくすると、押している間もゲージが減少する。

| 項目 | 初期値 | 内容 |
| --- | ---: | --- |
| 初期ゲージ量 | 0.8 | 開始時の操作ゲージ量 |
| バー速度倍率 | 1 | 自然減少と入力による増加の両方に掛ける倍率 |
| 自然減少量 / 秒 | 0.25 | 毎秒25ポイント減少 |
| 入力方式 | 長押しで連続増加 | 押すたびに増加（Press）/ 長押しで連続増加（Hold） |
| 1回押した時の加算量 | 0.085 | Pressで1回につき8.5ポイント増加 |
| 長押し中の加算量 / 秒 | 0.5 | Holdで毎秒50ポイント増加。自然減少も同時に適用 |

### 目標範囲・スピード・初期位置

| 項目 | 初期値 | 内容 |
| --- | ---: | --- |
| 中心位置の最小 / 最大 | 0.25 / 0.8 | 目標範囲の中心が移動する区間 |
| 範囲幅の最小 / 最大 | 0.18 / 0.3 | 目標範囲の幅の上下限 |
| 位置変化の基準時間 | 7 | 通常は2.1〜4.2秒で次の位置へ移動 |
| 位置の速度倍率 | 1 | 位置だけの速度。0で位置を固定 |
| 幅変化の基準時間 | 5 | 通常は1.5〜3秒で次の幅へ変化 |
| 幅の速度倍率 | 1 | 幅だけの速度。0で伸縮を停止 |
| 最短変化時間 | 0.12 | 1区間の時間の下限（速度倍率適用前） |
| 初期範囲を指定する | 無効 | 有効なら以下の初期中心・幅から開始。無効なら最大値側から開始 |
| 初期中心位置 / 初期範囲幅 | 0.8 / 0.3 | 指定した最小・最大内に補正 |

### ランダム性・急変・狭まり

| 項目 | 初期値 | 内容 |
| --- | ---: | --- |
| ランダム性全体 | 1 | 0で規則的な最小・最大間の往復。急変・狭まりイベントも無効 |
| 移動先のランダム性 | 1 | 0で中心の最小・最大間の往復、1で自由な移動先 |
| 幅のランダム性 | 1 | 0で幅の最小・最大間の往復、1で自由な幅 |
| 変化時間のランダム性 | 1 | 0で基準時間の45%秒に固定、1で30〜60%秒にばらつく |
| 急変の発生確率 | 0.25 | 位置・幅の更新ごとに速い変化を選ぶ確率 |
| 急変時の速度倍率 | 3 | 急変時の所要時間をこの値で割る |
| 狭まりの発生確率 | 0.35 | 幅の更新ごとに最小幅寄りを選ぶ確率 |
| 狭まり時に選ぶ幅の割合 | 0.15 | 幅区間の下側15%から選ぶ。0なら最小幅、1なら全区間 |
| 乱数シード | 0 | 0は開始ごとにランダム。0以外の整数で同じ動きを再現 |

全体のランダム性は各ランダム性とイベント確率にも掛かる。たとえば全体0.5・急変確率0.4なら、実際の急変確率は0.2。狭まり確率には幅のランダム性も掛かる。

### ハート・猶予・制限時間

| 項目 | 初期値 | 内容 |
| --- | ---: | --- |
| 初期ハート量 | 0 | 開始時の達成度。1なら開始時点で成功 |
| 必要な連続滞在時間 | 1 | ハートが増え始めるまでに必要な範囲内滞在時間 |
| ハート加算量 / 秒 | 0.05 | 条件達成後、毎秒5ポイント増加。0で加算停止 |
| 範囲外の猶予時間 | 0 | この秒数までの短い逸脱では連続滞在時間を維持。範囲外では加算しない |
| 猶予後のハート減少量 / 秒 | 0 | 猶予を超えた範囲外時間だけハートを減らす。0なら獲得済みの量を保持 |
| 制限時間 | 60 | ゲーム全体の制限時間 |

### プリセットと反映タイミング

Inspector下部の「やさしい・標準・難しい」で難易度設定全体を置き換える。Undoで戻せる。表示参照と結果イベントは保持する。プリセットから各数値を調整して難易度を詰められる。

| 項目 | やさしい | 標準 | 難しい |
| --- | ---: | ---: | ---: |
| 自然減少 / 秒 | 0.1 | 0.25 | 0.18 |
| 範囲幅 | 0.28〜0.4 | 0.18〜0.3 | 0.1〜0.22 |
| 範囲の位置・幅の速度倍率 | 0.7 | 1 | 1.3 |
| 全体のランダム性 | 0.3 | 1 | 1 |
| 必要な連続滞在秒数 | 0.3 | 1 | 0.8 |
| ハート加算 / 秒 | 0.18 | 0.05 | 0.1 |
| 範囲外猶予 | 0.2 | 0 | 0 |
| ハート減少 / 秒 | 0 | 0 | 0.025 |
| 制限時間 | 40 | 60 | 25 |

バー・ハートの速度と範囲の速度倍率はPlay中に反映。範囲速度の変更では位置が飛ばない。移動先・変化時間・イベントの設定は次の移動区間から反映。初期値・シードの変更は再スタートで反映する。

中心位置・幅は最大値側から開始する。範囲全体が0〜100%内に収まるよう中心位置を補正する。
次の移動先と幅をランダムに選び、到達するまで連続的に補間する。切り替え地点でも位置・速度・加速度が連続する補間を使い、速い変化のときも瞬間移動しない。
標準設定の通常変化時間は各 Period の30〜60%。急変ではその時間を急変時の速度倍率で割り、最短変化時間で下限を設定する。位置・幅の速度倍率は、その後の再生速度に掛かる。通常時も幅はランダムに選ぶため、狭まった後は再び広がることもある。
「急変の発生確率」を0にすると速い変化を無効化できる。「狭まりの発生確率」を0にすると最小幅寄りを優先するイベントを無効化できる。
位置や幅の変動を止めるには、それぞれの Minimum / Maximum を同じ値にする。
「必要な連続滞在時間」を0にすると、範囲内に入った直後からハートが増える。

## UI

画面右上の `MeterGameCanvas/RemainingTime` に「残り 60 秒」の形式で残り時間を表示する。Controller の「制限時間」と連動し、小数秒を切り上げてカウントダウンする。時間切れは0秒、途中で成功した場合はその時点の残り秒数で停止する。再スタートで設定した制限時間に戻る。位置・文字サイズ・色は `RemainingTime` のRectTransform / Textで調整できる。

`MeterGameCanvas/MeterBar` と、その上に操作案内 `InputPrompt` を表示する。参考画像 `Art/meter_bar.png` のピンク・金のフレーム、色付きゲージ、白いカーソル、ハートを参考に、uGUI のメッシュで描画している。参考画像自体を切り抜いて表示する実装ではない。

画面最上部の操作案内は、どちらの入力モードでも「Spaceキー : 増加、範囲内にゲージを留めよう！」を表示する。2.5秒ごとに0.7秒間、文字を最大1.1倍に拡大し、金色への変化とピンクの影で強調する。ゲーム終了時は案内を非表示にし、再スタートで再表示する。
`InputPrompt` の **Meter Game Input Prompt** コンポーネントで、案内文・強調間隔・強調時間・最大倍率・色を調整できる。フォントは `Art/Fonts/NotoSansJP-Bold.ttf`。案内はバーより上、画面上端から約40の位置を中心に配置している。

1920×1080を基準に、上部中央へ幅1120・高さ160、上端から60の位置に配置。CanvasScaler は画面幅に合わせて拡縮する。後からキャラクターや背景を追加できるよう、画面中央から下を空けてある。
位置・大きさは `MeterBar` の RectTransform の Anchored Position / Width / Height で変更する。

## 結果の受け取り・再開

- `MeterGameController` の **On Success / On Failure** に後続処理を登録できる。各ゲームにつき成否どちらかを1回だけ発火する。
- コードからは `controller.State.Result` / `Gauge` / `Heart` / `RemainingSeconds` / `HoldSeconds` / `TargetMinimum` / `TargetMaximum` を参照できる。
- 再開は `controller.RestartGame()`。Play 中は Controller コンポーネントのコンテキストメニュー **Restart Meter Game** からも実行できる。

## 検証方法

Unity の **Window → General → Test Runner → EditMode** から `SousakuTeam8.MeterGame.Tests` を実行する。
初期値、自然減少・押下加算、上下限、滞在待機、範囲外からの再進入、範囲の変動、成功・失敗、期限ちょうどの成功、再開、フレーム時間差、シーンのUI配置・参照接続を確認する。

ランダムな範囲変動について、急な変化中の連続性、幅の上下限、狭まりイベント、速度倍率、シードによる再現性、フレーム時間差を追加検証する。
難易度設定について、バー速度、Hold入力、軸別の速度・停止・再開、ランダム性0、初期範囲と初期ハート、範囲外猶予とペナルティ、プリセットを検証する。
入力方式について、長押し開始時に瞬間加算しないこと、連続加算のフレーム時間差、ゲーム中の方式切り替えも検証する。
Unity 6000.3.6f1 の検証用プロジェクトで EditMode テスト **30件すべて成功**。
1920×1080で開始時・ハート50%・成功時の描画も確認済み。
操作案内の通常表示・強調中・長押しモードの文言も1920×1080で描画確認済み。

手動では Play 中に Space の長押し・解放でカーソルを範囲内に維持し、ハートが蓄積することを確認する。成功の確認を短縮する場合は「ハート加算量 / 秒」を1、「必要な連続滞在時間」を0にする。失敗を短縮する場合は「制限時間」を1にする。

タイミング型の新しいMeterGameExampleについては [TimingMeterGame.md](TimingMeterGame.md) を参照。
