# Web版ビルド（2026-10-16）

`yoogen99/webBuild-ver10.10` のWeb対応を参考に、現在のゲームをPC・スマホのブラウザ向けに出力します。

## 出力

- フォルダー: `Builds/WebPlaytest-20261016/`
- 配布用: `Builds/WebPlaytest-20261016.zip`（ルートに `index.html`）
- 画面比率: 16:9。スマホは横向き推奨。
- Gzip圧縮とJavaScript側の解凍に対応。専用の圧縮配信設定は不要です。

## ビルド方法

Unity 6000.3.6f1 の Web Build Support を導入して、メニューの `Build > Browser Playtest (16:9)` を実行します。登録された有効な11シーンをまとめてビルドします。

コマンドラインからは、Unityに `-batchmode -quit -projectPath <プロジェクトの絶対パス> -buildTarget WebGL -executeMethod BrowserGameBuild.Build -logFile <ログの絶対パス>` を渡します。

## 起動方法

Webサーバーに出力フォルダーの中身を置き、`index.html` のURLを開きます。HTMLを直接ダブルクリックして開く方法では起動できません。

このPCで確認する場合、プロジェクトのルートで `node work/preview-web-build.cjs` を実行し、`http://127.0.0.1:8086` を開きます。Node.jsが必要です。この確認用URLはこのPC内でのみ有効です。

スマホで遊ぶ場合は、Webサーバーに配置したURLをスマホのブラウザで開いてください。
