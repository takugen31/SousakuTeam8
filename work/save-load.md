# セーブとロード 初期版

Escメニューの「セーブ」「ロード」から、手動6枠を選択します。各枠には保存日時・場面・現在の文章を表示します。既存枠への上書きとロード時は確認画面を表示します。

## 保存する状態

- 共通・カヨ・ヨワシの会話のシナリオと行。選択肢は同じ行から再表示します。
- 名前の公開状態、既に表示した相談開始演出。
- 背景、左右の立ち絵・表情・表示状態・配置。
- アーカイブの取得済み情報と既読状態、好感度、両方の探索の取得済み対象。
- 探索中の部屋、調査画面の対象、探索会話の位置と終了位置、カヨの紙の背景。
- キャラ選択の導入文章を送ったかどうか。
- カヨの救出成功／失敗。ロード後も成功限定の紙の会話へ進む条件を維持します。

ロード時は保存済みのセリフの好感度・情報取得を再実行しません。全文表示済みのページは全文で、表示途中なら同じページの先頭から表示します。オートはロード時にOFFに戻し、意図せず次へ進むことを防ぎます。BGMは復元先の会話／シーンに対応する曲になります。

## 保存できない場面

- キャッチゲーム・日記パズル中。
- シーン遷移・暗転・相談開始演出・スキップ確認中。
- キャラ選択の「話してみますか？」確認中。
- タイトルと、今回対象外のモテル個別ルート。

タイトルの「始める」と「ゲームを終了」の間に「ロード」を表示します。共通の6枠ロード画面を開き、「← タイトル」で戻ります。Escメニューからのロードも可能です。

## 保存の寿命

- Unity Editorでは、プレイモード開始時に6枠をリセットします。終了時には削除せず、次の開始で消します。
- 同じプレイセッション中に「最初から」を選んでも6枠は消しません。
- リセット対象はGameSave.Slot.v1.0～5のみ。他アプリの保存や無関係な設定は削除しません。
- ビルド版では開始時のリセット処理は含まれず、PlayerPrefsに保持します。

## 検証とプレイテスト

`work/verify-save-load.ps1`は実際の保存・検証・ロード処理を、ゲームの保存領域に触れないメモリー上の模擬環境で検査します。6枠、JSONの往復、破損データ、進行の巻き戻し、失敗時の保護、選択／探索、Editor開始時リセットを検査します。Unityでの画面操作はまだ検証していません。

Unityで次を確認してください。

1. 会話を保存して数ページ進め、ロードすると保存した文章・立ち絵・背景に戻る。
2. 選択肢を表示して保存し、別の選択をしてからロードすると同じ選択肢へ戻る。
3. 探索で部屋を切り替え、調査画面・調査後の会話で保存してそれぞれ復元する。情報取得が増えたり、最後の調査が飛ばされたりしない。
4. カヨ救出の成功／失敗の両側で保存・ロードし、成功限定会話の有無が変わらない。
5. 上書き・ロード確認で「いいえ」を選んでキャンセルする。
6. セッション内の「最初から」で枠を維持し、プレイモードを終了・開始すると6枠が空になる。

## 設定変更時

セーブの形式番号は1です。削除・名称変更されたシナリオや行の復元には対応していません。Editorで開始時リセットする現行方針により、編集後の古いセーブを次のプレイへ持ち越しません。
