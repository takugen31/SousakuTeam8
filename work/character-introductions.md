# カヨ・ヨワシ自己紹介の見上げ

カヨ：`chapter2_kayo_001`「私は大葉カヨ。よろしく」の表示前。
ヨワシ：`chapter2_yowashi_001`「この左腕に封印されし悪魔…」の表示前。
通常の立ち絵が描画されるより先に DialogueRoot を非表示にして、独立した背景・立ち絵コピーで演出。

モテルと同じ見上げ処理を共用。二人の全身立ち絵は膝が画面下端付近に来る画角（注視位置はスプライト下端から50%）から、
カヨは84%、ヨワシは89%の顔中心へ9.5秒で移動し、0.6秒停止。
0.3秒で暗転し、通常会話画面へ戻して0.3秒で明転。本文は明転後に表示。
一度の会話再生で同じ自己紹介演出を繰り返さず、再開始時は再生できる。
Esc中は一時停止。元の立ち絵・背景・シナリオ本文は変更しない。

ビルド・初登場演出の回帰検査を実施。Unity Play Mode の実表示は未確認。
